# P03 — The Y/A 2025/2026 data file

## Read first

- [`../research/04-rate-tables.md`](../research/04-rate-tables.md) — the verified figures
- [`../research/12-open-questions.md`](../research/12-open-questions.md) — **what is not verified**
- [`../spec/data-model.md`](../spec/data-model.md) — the shape

## Task

Write `data/tax-years/2025-26.json`.

Every value comes from the research documents, **with the `src` pointer they cite**. This
prompt is transcription, not research. If a figure you need is not in `04-rate-tables.md`
with a citation, it does not go in the file — record the gap and move on.

Verified and available:

- Personal relief — [IRA Sch.5 para 2(a)(v), ins. Act 2/2025 s.5(3)]
- The normal ladder, five bands — [IRA Sch.1 para 1(1D), ins. Act 2/2025 s.3(1)(b)]
- The 15% maximum-rate cap and its condition — [IRA Sch.1 para 1(6), ins. Act 2/2025 s.3(1)(d)]
- Special business rate — [Act 2/2025 s.3(1)(c)]
- AIT on interest — [Act 2/2025 s.3(3)]
- Instalment dates — [IRA s.90(2)(a)]; return-due rule — [IRA s.93(1)]

Carry `verified: false` on capital gains and terminal benefits: both are 2017 text, and
the capital gains rate is **known superseded** by an act not held (Q42).

## Do not

- **Fill any gap from memory or from a web search.** Recognition is not a source.
- Model the 15% as a separate rate schedule. It is a cap on the ladder.
- Store the return due date as a literal. It is a rule: eight months after year end.
- Mark anything `verified: true` that the research marks `partial` or `unverified`.

## Acceptance

- `npm run build` passes, meaning schema validation accepted the file
- A test asserts the file's personal relief and all five band rates match
  `04-rate-tables.md` exactly
- A test asserts every `src` in the file resolves
- `node scripts/check-citations.mjs` still passes

Every value written with its citation, and an explicit list of every field you left out
because no cited source supported it.
